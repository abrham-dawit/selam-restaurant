# Selam Restaurant — Website

A website for Selam Restaurant, an Eritrean & Ethiopian kitchen. "Selam" (ሰላም) means peace — the site is built around that warmth: rich colors, the real menu, and a proper introduction to the coffee ceremony.

## What's on it

- **Full menu, organized by category** — mains (zigni, tibs, doro wat, kitfo), vegetarian & fasting dishes (shiro, beyaynetu, misir wat), starters, and drinks & coffee — each with the Amharic/Tigrinya name, a plain-English description, price, and tags (spicy, vegan, house favorite).
- **Our Story** — a short section on the cooking tradition: berbere, niter kibbeh, slow-fermented injera, and eating family-style.
- **Hours & Location** — with spots for the address, hours, and phone.

## Before this goes live for real

The address, hours, and phone on the page are **clearly marked placeholders** (red dashed boxes) — swap in the restaurant's real details in `index.html` first. Menu prices are typical starting points too; adjust them to the real menu. Everything else — layout, categories, descriptions — is ready.

## Running it

Plain HTML, CSS, and JavaScript. Open `index.html`, or host the folder on any static host (GitHub Pages works). Menu items live in one list at the top of `app.js`, so editing the menu doesn't mean touching HTML.
